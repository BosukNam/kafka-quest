# 카프카 퀘스트

내가 **메시지(미사일)** 가 되어 프로듀서 발사대에서 토픽의 파티션 레인으로 날아가고, 컨슈머 로봇이 나를 가져가 처리하는 Kafka 학습 게임입니다.

**플레이: https://bosuknam.github.io/kafka-quest/**

왼쪽 발사대가 프로듀서, 가운데 레인이 파티션(로그), 오른쪽 로봇이 컨슈머입니다. 메시지를 쏘면 레인 끝 칸(오프셋)에 붙고, 로봇이 순서대로 가져갑니다. 장마다 월드 설정이 달라지고(레인 수, 로봇 수, acks, 재시도 방식…), 중간중간 퀴즈로 왜 그런지 확인합니다. 장이 끝나면 게임 속 표현과 진짜 이름을 표로 보여 줍니다.

| 편 | 장 | 직접 겪는 것 |
| --- | --- | --- |
| 기본 | 1. 첫 발사 | 토픽·오프셋, 읽어도 안 지워지는 로그, 다른 그룹은 처음부터 읽음 |
| 기본 | 2. 파티션과 키 | 같은 키 = 같은 레인, 키 없으면 아무 레인, 파티션 안에서만 순서 보장, 핫 파티션 |
| 기본 | 3. 컨슈머 그룹과 커밋 | 파티션보다 많은 로봇은 놂, 커밋 없이 재시작하면 중복(at-least-once) |
| 기본 | 4. 복제와 acks | acks=1 에서 리더가 죽으면 유실, acks=all + retries 는 새 리더에 재전송, ISR·min.insync.replicas |
| 심화 | 5. 재시도 | 제자리 재시도의 헤드 오브 라인 블로킹 → 재시도 토픽, 백오프, 멱등 소비, 순서 손실 |
| 심화 | 6. 데드 레터 큐 | 포이즌 메시지가 3번 실패 후 DLQ 로, 영구 오류와 일시 오류 구분, DLQ 헤더 |
| 심화 | 7. 리밸런싱 | 로봇 추가·이탈 때 stop-the-world, max.poll.interval.ms, cooperative sticky, static membership |
| 심화 | 8. 컨슈머 랙과 파티션 늘리기 | 자동 발사 폭주를 로봇 추가·레인 추가로 막기, 파티션 수 = 병렬 상한, 늘리면 키 배정이 바뀜 |
| 심화 | 9. 중복과 멱등 프로듀서 | ACK 유실 → 재전송 → 두 번 결제, enable.idempotence 의 시퀀스 검사, 컨슈머 멱등 키 |
| 심화 | 10. 로그 컴팩션 | 키별 마지막 값만 남는 청소, 툼스톤, retention 과의 차이, __consumer_offsets |

## 조작

- ↑ ↓ (W S) 또는 레인 클릭·탭: 조준할 레인 고르기
- Space · Enter, 발사대 클릭, 오른쪽 아래 '발사' 버튼: 발사. 대사도 Space 로 넘김
- 퀴즈·메뉴·장 완료 화면: 방향키로 옮기고 Space(Enter)로 고르기, 퀴즈는 숫자 1~4 도 가능
- 휴대폰: 왼쪽 아래 ▲▼ 로 조준, 오른쪽 아래 '발사'
- 잘못된 레인이나 오답은 하트 -1 과 해설. 하트를 다 쓰면 그 장을 처음부터

## 구조

빌드 도구 없이 정적 파일만 씁니다. (OIDC 퀘스트와 같은 구성)

- `index.html`, `style.css`: 화면과 HUD
- `game.js`: 월드(레인·로봇·브로커) 시뮬레이션, 미사일 비행, 복제·ack·크래시·재시도·DLQ·리밸런싱·컴팩션 처리, 대화·퀴즈·카드 엔진
- `quests.js`: 장·단계 데이터. `say` / `quiz` / `fire` / `event` / `wait` / `burst` 단계를 조합해 새 장을 추가할 수 있습니다

로컬 실행: `python3 -m http.server` 후 http://localhost:8000
